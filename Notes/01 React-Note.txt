programatic navigation:
==========================
in case we want to make a page navgate to another programatically (after clicking a button/after specific time etc... ) then we can use hook called "useNavigate"

URL Parameters:
================
to get url Parameters, you can use useParams hooks.
ex: https://amazon.com?pid=123456

nested routes:
==============
incase one route is inside another route they are termed as nested routes. for them we can use <Outlet /> to print child routes.
