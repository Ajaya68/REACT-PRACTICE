Hook:
=====
    -Hooks are pre defined functions in react from version 16.
    -These hooks 
        -holds the state(useState)
        -run side effect(useEffect)
        -access life cycle behavior
        -integrate with cuncurrent rendering
    -hooks must be present in top level because react them by call order.
    -Main or popular hooks we use :
        
        i.useState  
        ===========
        -its purpose is to make state of a value and maintains it.

        State is Mutable
        =================
        const[value,setValue]=useState(initialValue)
        -value containes initially initialValue and setValue is a function
         that is used to change/replace the value.
        -state is asynchronous so the next synchronous lines will run first
         Ex: setValue(5)

        ii.useEffect
        ============
        -it is used to run side effect/async function such as API
         calls, timer or cleanup logic.
         useEffect(callbackFunction, dependencyArray)
        -Empty dependence array - run once
        -dependencyArray with value - run at starting and everytime the state of
         those values changes.
        -no dependencyArray - run at starting and everytime, any value state changes.

        iii.useMemo:
        ============
        -it is used for memorize or cache expensive calculations
        useMemo(callbackFunction, dependencyArray)
        -This should be used for strict calculations

        iv.useCallback:
        ===============
        -it is used to cache function.
        -it maintain the stable identity of function.
        -it is useful when passing callbacks to memorized children
        -it is also useful to safeguard from re-render for children dependencies.
        useCallback(callbackFunction, dependencyArray)

        v.useRef:
        =========
        -it is used to do DOM manipulation.
        -it assumes Reference for every element of DOM.
        -Mainly used to store values, counters, flag, trimers etc...
