What is React?
===============
    -React is an open-source javascript library, which is used 
     to build user interfaces.
    -React is Developed and maintained by Meta(Facebook).

-In 2012 so many around the globe uses Facebook. To make it better experience, they 
build their own library react and 2014 they open sourced it.

is React.js and React Native are same?
======================================
    -React.js is used for web application/website.
    -React Native is used for mobile application.

What are the major uses of React?
=================================
    -React is mainly used to build UI of SPA and Progressive Web Apps(PWA).

SPA:- Single page application is nothing but an application that loads a specific
      part of UI instead of whole app.
PWA:- An application that feels like native app is known as PWA.

What are Compititors and react advantages over them?
====================================================
    -React can be replaced with angular, vue.
    -Angular is a framework of JS and Vue is also a library of JS.
    -React is more simpler, easy and it supports Virtual DOM for quickness.

Procedure to Build first React app
===================================
    -Install Vs Code editor
    -install NPM [Node Package Manager]
    -We need a bundler to get react tamplate bundle. Using this, we don't need to create every
     Single file, we will get basic boilerplate code.
    
NPM:
==== 
    -it is a software used by developers to download, install, unpdate, delete any framework or 
     library from the project.

    To Create react app use these following commands:
        >npm create vite@latest
    To run application run this command:
        >npm run dev

React Files
============
    -React code contains  files called jsx [javascript extensible] using jsx we 
     can write HTML inside javascript.
    -Every jsx file should return one HTML element.
    -Always name of file and component/function name should be same.
     [better Start function name with uppercase].
    -in jsx class proporty should written as className, because class is a keyword in js.
    -in jsx, it is mandatory to close all tags including self closing tags.

    For production use: >npm run build

Files & Folders
===============
    package.json-       it contains meta data about our application.
    package-lock.json-  it contains meta data of package.json.
    vite.config.js-     contains setting of Vite.
    .gitignore-         contains files that are ignored by git.
    eslint-             notifies and observer error in code.
    node_modules-       it containes actual code of all package.
    public-             for static resources.
    src-                for dynamic resources.
    index.html-         main and entry point of our application. it contains
                        head and body.
    main.jsx-           it loads app.jsx into div with id "root". in react we call
                        loading as rendering.
    App.jsx-            contains actual body code in jsx format.


React basically deals with 4 topics:
    i.components

    iv.API's

components:
===========
    -React divides the whole UI of a website into a reusable logical parts
     called component, using which we can build application.
        -reusable
        -simple
        -can be functional or class
        -return jsx but all jsx files/function must return one element only.
