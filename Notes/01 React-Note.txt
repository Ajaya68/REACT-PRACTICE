React basically deals with 4 topics:
    i.components
    ii.Props
    iii.State and Virtual DOM
    iv.API's

components:
===========
    -A component is a reusable and independent part of the user interface.
    -React divides a large UI into smaller logical and reusable parts called components.
        Example:
            A shopping website can have:
                -Navbar
                -ProductCard
                -ProductList
                -Cart
                -Footer
    -Each part can be created as a separate component.

Advantages of Components
========================
-Reusable
-Easy to maintain
-Easy to understand
-Organized
-Can be composed together to create a complete application

Types of Components
===================
    -React components can mainly be written as:

        -Function Components
        -Class Components

    -Modern React development mainly uses function components.
    Example:
        function Student() {
            return <h1>Student Component</h1>;
        }

Props:
======
    -Props is short for Properties.
    -Props are used to pass data from a parent component to a child component.
    -Props are received by a component as an object containing key-value pairs.
Example:
function Student(props) {
    return <h1>{props.name}</h1>;
}

function App() {
    return <Student name="Ajaya" />;
}

Here:
name = "Ajaya"
-is passed from the App component to the Student component.

Important Points about Props
=============================
-Props are used to pass data between components.
-Props are generally passed from parent to child.
-Props are read-only inside the receiving component.
-Props help make components reusable.

State:
======
    -State is data that belongs to a component and can change over time.
    -When state changes, React can re-render the component so that the UI displays the updated data.

Example:
A counter can have:
    count = 0
After clicking a button:
    count = 1
The UI updates according to the new state.

Important Characteristics of State
==================================
    -State can change over time.
    -State is generally local to the component that owns it.
    -Changing state can cause the component to re-render.
    -State is used for dynamic and interactive UI.

How to Manage State Using useState
==================================
    -React provides a Hook called useState for managing state in function components.

What is a Hook?
===============
    -A Hook is a special React function that allows function components to use React features such as:
        -State
        -Effects
        -Context
        -References

Examples:
        useState()
        useEffect()
        useContext()
        useRef()

useState():
===========
    -The useState Hook gives us:
        -The current state value
        -A function used to update that state
    -It returns these values in the form of an array.

Syntax:
const [value, setValue] = useState(initialValue);

Example:
const [count, setCount] = useState(0);

Here:
count     → current state value
setCount  → function used to update the state
0         → initial value

Complete Example:
import { useState } from "react";

function Counter() {

    const [count, setCount] = useState(0);

    return (
        <div>
            <h1>{count}</h1>

            <button onClick={() => setCount(count + 1)}>
                Increase
            </button>
        </div>
    );
}

export default Counter;

When the button is clicked:
0 → 1 → 2 → 3 → 4 ...
The state changes and React updates the UI.

VIRTUAL DOM
=============
-The Virtual DOM is a lightweight representation of the UI that React uses to help 
 determine what needs to change.

When state or props change:

-React creates an updated representation of the UI.
-React compares it with the previous representation.
-React determines what actually needs to change.
-React updates the required parts of the actual DOM.
This helps React update the UI efficiently.
